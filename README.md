# Walk vs. Run Classification: Activity Recognition

**Duration:** [28th Nov 2025 – 5th Dec 2025]

**Project Type:** IoT Data Analysis & Deep Learning

# Overview
- This project focuses on classifying human physical activity—specifically distinguishing between walking and running—based on time-series data collected from wrist-worn motion sensors.
- By analyzing accelerometer and gyroscope readings, the system captures temporal dynamics to accurately predict the user's movement state.

# Key Features
- Time-Series Analysis: Processed sequential sensor data (Acceleration X/Y/Z, Gyroscope X/Y/Z) from iOS devices.
- Deep Learning Implementation: Designed and trained Long Short-Term Memory (LSTM) neural networks to capture temporal dependencies in movement patterns.
- Model Benchmarking: Compared the performance of deep learning models against classical algorithms like Random Forest and Support Vector Machines (SVM).
- High Accuracy: Achieved robust classification results suitable for deployment in fitness tracking applications.

# Technologies Used
- Python
- pandas, numpy
- TensorFlow / Keras (LSTM)
- scikit-learn (Random Forest, SVM)
- Matplotlib, Seaborn (EDA)
